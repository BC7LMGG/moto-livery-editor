# Livery Studio

Редактор графики для мотоциклов и квадроциклов. Работает как статический сайт на GitHub Pages: 3D-модель, UV-развёртка, слои изображений и экспорт текстур. Сервер, аккаунт и база данных не нужны.

**Сайт:** https://bc7lmgg.github.io/moto-livery-editor/

## Использование

1. Выберите транспорт. Загружаются только его mesh-детали и маски, весь каталог сразу не скачивается.
2. Выберите деталь в списке или нажмите на неё в 3D.
3. Добавьте PNG, JPG, WebP или AVIF кнопкой или перетащите файлы на развёртку. Каждая картинка становится отдельным слоем.
4. Перетаскивайте слой; углы рамки меняют размер, кружок над рамкой — поворот. Shift при изменении размера позволяет менять пропорции; при повороте — шаг 15°.
5. В панели справа настройте порядок, непрозрачность, отражение, положение и цвет основы. Слой можно скрыть, скопировать, переименовать или удалить.
6. В «Обрезать» выделите прямоугольную область. «Применить обрезку» обрезает текущий слой; «Область новым слоем» оставляет оригинал и создаёт отдельную перемещаемую область.
7. Скачайте одну деталь в PNG или весь набор в ZIP. UV-подсказки, рамки и элементы интерфейса в изображения не входят.

Ctrl+Z — отмена; Ctrl+Shift+Z / Ctrl+Y — повтор. Стрелки перемещают выбранный слой; Shift увеличивает шаг. Колесо вращается в 3D для приближения; Ctrl+колесо над развёрткой меняет её масштаб. В 3D также доступны общий вид, приближение к детали и её изоляция.

«Сохранить проект» скачивает файл `.livery.json` с картинками и слоями текущего транспорта. Его можно открыть позже через «Открыть проект с компьютера». Правки разных моделей сохраняются в памяти до закрытия вкладки. Для продолжения работы после закрытия сохраните проект файлом.

## Модели и текстуры

В каталоге **16 транспортов, 74 mesh-детали и 76 масок**. Первой открывается Kawasaki KX250F. Все доступные mesh-детали выбранной модели загружаются вместе с сохранением их взаимного положения.

В исходном наборе отсутствуют mesh для двух масок:

- `KWSKX250F_1110_HeadlightMask`
- `KTM690SMCR_0868_HeadlightMask`

Эти детали отмечены «только 2D»: развёртка и экспорт работают, 3D-просмотра этих двух деталей нет. Сайт показывает предоставленные части для графики; остальной мотоцикл не добавлялся.

Готовые FBX преобразованы в GLB без открытия Blender. Маски `*_MASK.png` скопированы из исходной папки без изменений. Исходные файлы не менялись; `.blend`, FBX, обзоры и проверки на сайт не загружены. Геометрия, UV и нормали проверены официальным glTF Validator.

Экспорт по умолчанию использует размер исходной развёртки. Можно выбрать 4096, 2048 или 1024 пикселя. ZIP содержит PNG для каждой детали и `pack.json` с идентификаторами деталей и размерами. Переключатель прозрачного фона влияет на PNG; в 3D для удобства остаётся цветная основа.

В одной детали доступно до 32 слоёв, изображение — до 25 МБ. Длинная сторона добавленной картинки больше 4096 пикселей уменьшается до 4096. 3D-превью использует текстуры 1024×1024; экспорт собирается отдельно в выбранном разрешении. Обрезка прямоугольная.

## Приватность и загрузка

Пользовательские изображения и проекты обрабатываются локально. На сайте нет загрузки картинок на сервер, аналитики и внешних CDN. HTML, JavaScript, модели и маски скачиваются с этого же GitHub Pages. Для 3D нужен браузер с WebGL2; если 3D недоступно, редактор развёртки и экспорт могут продолжать работать.

Весь набор ресурсов занимает около 47 МиБ. При открытии Kawasaki KX250F загружается только небольшой комплект этой модели и редактор. Следующая модель загружается при её выборе.

## Разработка

Нужен актуальный Node.js и pnpm. Зависимости закреплены в `pnpm-lock.yaml`.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm dev
```

Локальный адрес: `http://127.0.0.1:8794/moto-livery-editor/`. Открытие `index.html` через `file://` не поддерживается: загрузке моделей нужен HTTP-сервер.

```sh
# Проверка GLB официальным валидатором
pnpm validate:assets

# Браузерные проверки; локальный сервер должен быть запущен.
# scripts/test-editor.mjs настроен на установленный Google Chrome в Windows.
pnpm test

# Повторный импорт из папки с готовыми FBX и MASK PNG
pnpm assets "C:/path/to/UV_V2"
pnpm build

# Архив только файлов, необходимых для статического размещения
node scripts/package-site.mjs
```

При добавлении новых транспортов дополните названия в `scripts/import-assets.mjs`. Файлы mesh ожидаются в `Meshes` с именами `<part>_UV_V2.fbx`; маски — в папке транспорта с именами `<part>_MASK.png`. Импорт создаёт `assets/catalog.json` и `assets/models/`.

`src/app.js` — интерфейс и проекты; `src/layers.js` — слои, обрезка и композиция; `src/viewer.js` — 3D. Сборка создаёт `dist/app.js`. Для GitHub Pages уже собранные `dist` и `assets` хранятся в репозитории: после изменения исходников нужно выполнить `pnpm build`.

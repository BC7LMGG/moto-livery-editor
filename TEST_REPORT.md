# Проверка Livery Studio

Локальная проверка обновлённой тёмной темы и инструментов: **8 октября 2026 года**, установленный Google Chrome, Playwright, WebGL через SwiftShader. Итог: **18 групп браузерных проверок прошли**, ошибок JavaScript нет.

Сценарий проверяет загрузку всех моделей, слои, обрезку, файлы проектов и экспорт. Его можно запускать локально или на **https://bc7lmgg.github.io/moto-livery-editor/** через переменную `EDITOR_URL`. В локальном прогоне зарегистрировано 115 GET-запросов на собственный origin; запросов на отправку пользовательских изображений не было. Это число относится к тесту, который по очереди открывает все 16 транспортов, а не к одному посещению страницы.

Официальный **Khronos glTF Validator 2.0.0-dev.3.10** проверил каждый GLB: **16 из 16, 0 ошибок, 0 предупреждений**. UV-атрибуты применяются к текстурам, создаваемым редактором во время работы.

Дополнительно сверены исходные файлы в папках `Meshes`: 74 готовых FBX и 74 импортированных mesh-детали, пропущенных mesh нет.

Автоматические проверки: `scripts/test-editor.mjs` и `scripts/validate-assets.mjs`. Подробные машинные результаты и снимки интерфейса находятся в локальной папке `outputs/`; они не публикуются в репозитории.

Это функциональные проверки редактора. Реальные мобильные устройства, все браузеры и нагрузка GitHub Pages отдельно не тестировались. В исходном наборе две маски без mesh: KX250F HeadlightMask и KTM 690 HeadlightMask. Они доступны для 2D-редактирования и экспорта.

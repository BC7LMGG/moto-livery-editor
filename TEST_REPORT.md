# Проверка Livery Studio

Локальная проверка сборки: **8 октября 2026 года**, установленный Google Chrome, Playwright, WebGL через SwiftShader. Итог: **16 групп браузерных проверок прошли**, ошибок JavaScript нет.

| Проверка | Результат |
| --- | --- |
| Загрузка всех 16 моделей | Все GLB загружаются; mesh-части доступны вместе |
| Kawasaki KX250F | 4 mesh-детали, 5 масок; каталог содержит 16 транспортов |
| Несколько изображений, порядок и непрозрачность | Проверены фактические пиксели экспортированного PNG |
| Положение, поворот, размер, отражение | Проверены параметры слоя и перемещение указателем |
| Обрезка изображения | Выбранный участок сохраняет своё положение, размер пересчитывается |
| Область отдельным слоем | Оригинальный слой сохраняется, новый редактируется независимо |
| Скрытие, копирование, удаление | Состояние корректно, отмена восстанавливает слой |
| Отмена и повтор | Параметры и слои восстанавливаются |
| Живой 3D-просмотр | Текстура mesh обновляется при изменениях слоя |
| UV-подсказка | PNG с включённой и выключенной подсказкой идентичны |
| Прозрачный PNG | Альфа вне изображений равна нулю |
| ZIP для KX250F | Пять PNG, `pack.json`, правильные детали и разрешение 1024×1024 |
| Локальный файл проекта | Изображения и три слоя восстанавливаются после очистки |
| Неподдерживаемый проект | Не заменяет текущую модель |
| Переключение моделей | Ранее созданные слои остаются в памяти сессии |
| Экран 390×844 | Нет горизонтального переполнения; сохранение проекта доступно |
| Сетевые запросы | Только GET на собственный origin; пользовательские изображения не отправляются |

Официальный **Khronos glTF Validator 2.0.0-dev.3.10** проверил каждый GLB: **16 из 16, 0 ошибок, 0 предупреждений**. UV-атрибуты применяются к текстурам, создаваемым редактором во время работы.

Автоматические проверки: `scripts/test-editor.mjs` и `scripts/validate-assets.mjs`. Подробные машинные результаты и снимки интерфейса находятся в локальной папке `outputs/`; они не публикуются в репозитории.

Это функциональные проверки редактора. Реальные мобильные устройства, все браузеры и нагрузка GitHub Pages отдельно не тестировались. В исходном наборе две маски без mesh: KX250F HeadlightMask и KTM 690 HeadlightMask. Они доступны для 2D-редактирования и экспорта.

# Проверка Livery Studio

Локальная проверка новых моделей, скачивания UV и тёмного холста: **8 октября 2026 года**, установленный Google Chrome, Playwright, WebGL через SwiftShader. Итог: **21 группа браузерных проверок прошла**, ошибок JavaScript нет.

Сценарий проверяет загрузку всех моделей, слои, обрезку, файлы проектов и экспорт. Его можно запускать локально или на **https://bc7lmgg.github.io/moto-livery-editor/** через переменную `EDITOR_URL`. В локальном прогоне зарегистрировано 195 GET-запросов на собственный origin; запросов на отправку пользовательских изображений не было. Это число относится к тесту, который по очереди открывает все 20 транспортов и скачивает новые маски, а не к одному посещению страницы.

Официальный **Khronos glTF Validator 2.0.0-dev.3.10** проверил каждый GLB: **20 из 20, 0 ошибок, 0 предупреждений**. UV-атрибуты применяются к текстурам, создаваемым редактором во время работы.

Дополнительно сверены исходные файлы в папках `Meshes`: 111 готовых FBX и 111 импортированных mesh-деталей, пропущенных mesh нет. Прежние 16 GLB и 76 масок не изменены; новые 37 PNG совпадают с файлами из четырёх указанных папок.

Автоматические проверки: `scripts/test-editor.mjs` и `scripts/validate-assets.mjs`. Подробные машинные результаты и снимки интерфейса находятся в локальной папке `outputs/`; они не публикуются в репозитории.

Это функциональные проверки редактора. Реальные мобильные устройства, все браузеры и нагрузка GitHub Pages отдельно не тестировались. В исходном наборе две маски без mesh: KX250F HeadlightMask и KTM 690 HeadlightMask. Они доступны для 2D-редактирования и экспорта.
